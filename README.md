# ADIM-İST prototipleri

Lise öğrencilerinde adım temelli teşvik çalışmasının tıklanabilir prototipleri (öğrenci uygulaması, gişe tableti, araştırmacı paneli). Sayfalardaki öğrenci ve okul verileri sentetiktir. Bu depoda kişisel veri bulunmaz.

`canli.html` yalnızca giriş yapan araştırma ekibine, telefondan gönderilen kodlu deneme adımlarını gösterir (veri Supabase'te tutulur, depoda değil). `sunucu/` klasöründe tablo kurulum SQL'i ve telefon uygulamasına eklenen gönderim betiği vardır.
